# Solyd — Introdução ao Python | Projeto 1

Repositório com arquivos de estudo e exercícios da trilha **Introdução ao Python**, da Solyd.

## Conteúdos

- Listas, tuplas, dicionários e conjuntos
- Laços de repetição e funções
- Tratamento de erros e exceções
- Leitura e escrita de arquivos TXT
- Importação e exportação de CSV
- Agenda de contatos com cadastro, consulta, edição, exclusão e persistência em CSV

## Como executar

Tenha o Python 3 instalado. Entre na pasta `projeto1` e execute o arquivo desejado, por exemplo:

```bash
python lista.py
python agenda.py
```

A agenda interativa utiliza `database.csv` como base local.

## Estrutura

Os exemplos Python e os arquivos TXT/CSV utilizados nos exercícios ficam na pasta `projeto1/`. Configurações locais da IDE não foram incluídas.
